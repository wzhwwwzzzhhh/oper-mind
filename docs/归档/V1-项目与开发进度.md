## 1. V1 产品边界

V1 是会话式多 Agent DevOps Copilot。会话工作台是正式入口，服务中心管理服务接入、状态、监控和调查入口。PostgreSQL 慢查询是验证主链的技术切片，不等于整个产品边界。

正式链路连接消息、Run、多 Agent Runtime、ToolGateway、Connector、证据、结果和安全 Trace；风险动作另走提案、人工审批、白名单执行与独立 Verify。

后端入口为 `backend/src/app.py` 的 `src.app:app` 与 `/api/v1`；前端入口为 `frontend/src/app/App.tsx`。演示靶场不作为正式产品入口。

原始定义与约束见 [产品定义](../事实源/产品定义.md)、[架构与开发路径](../事实源/架构与开发路径.md)、[开发规范](../事实源/开发规范.md)；原阶段记录见 [路线图](../事实源/路线图.md)。

## 2. 已有模块与复用边界

### 会话与执行留痕

已有会话、消息、搜索、归档与恢复、编辑与删除、导出，以及 Run、SSE、安全 Trace、取消、重跑和运行记录。会话与消息的大部分交互可复用；调查入口、服务绑定和诊断结果展示需要按 V2 目标调整。

代码入口：`backend/src/application/`、`backend/src/domain/records.py`、`backend/src/api/v1/`、`frontend/src/features/workbench/`、`frontend/src/features/session/`。

### 模型管理

已有 Provider 与 API Key 管理、模型枚举、mock/real 切换、参数配置、用量统计与估算费用，以及近期合入的角色模型装配。用量和估算费用不等于供应商账单。

代码入口：`backend/src/application/model_*.py`、`backend/src/core/llm.py`、`frontend/src/features/models/`。角色模型代码已合入，但路线图明确 P14 尚未形成对应正式阶段，不能把迁移文件名当成正式阶段交付。

### 智能运行内核与工具边界

已有 Coordinator、DB/Server/Log/Knowledge/Report 角色，以及 LangGraph 编排和领域 Agent 的 ReAct 子图。ToolGateway 负责受控调用、参数校验、权限边界、超时、脱敏与审计摘要。

已有 Harness 契约内核、兼容映射与回归护栏，以及 Runtime 唯一终态、安全失败、工具超时和迟到结果隔离。P10 Adapter 契约用于参考与兼容测试，不能视为已经切换生产装配或拥有业务状态的通用运行控制面。

代码入口：`backend/src/core/`、`backend/src/application/runtime_contracts.py`、`backend/src/application/runtime_safety.py`、`backend/src/domain/harness_contracts.py`。

### 服务、知识与运维能力

已有服务注册、管理、连接测试、服务上下文、监控与服务详情；有 PostgreSQL、Redis、MySQL 相关受限 Connector/Tool，以及日志、主机指标和 Markdown 知识检索资产。P12 三服务实现已合入，真实验收状态见下一节。

这些是业务适配资产，不等同通用 Capability 系统。数据库指标、锁与连接池、监控页面、服务详情及固定调查入口具有较强运维耦合。

代码入口：`backend/src/application/service_*.py`、`backend/src/infrastructure/services/`、`backend/src/tools/`、`frontend/src/features/services/`、`frontend/src/features/monitor/`、`frontend/src/features/knowledge/`。

### 动作、审批与审计

已有提案、审批、固定白名单动作、执行、独立验证、审计检索与导出。当前动作模板以固定联合索引重建为边界；已有审批框架不授权新增任意动作。

代码入口：`backend/src/application/action_*.py`、`backend/src/application/controlled_action_catalog.py`、`backend/src/domain/actions.py`、`frontend/src/features/approvals/`、`frontend/src/features/audit/`。
