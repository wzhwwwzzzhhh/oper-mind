## 已确认的核心决策

1. **全局导航改窄图标栏**：最左 62px 图标导航（会话工作台 / 服务中心 / 服务监控 / 文档知识库 / 模型设置），会话与运维两模式共用同一壳。
2. **彻底去掉右侧栏**（用户明确："原来主页面的右侧加功能确实有点怪"）。
3. **会话主区居中，保留 780px 内容宽度限制**。
4. **第二栏随模式切换**：会话模式 = 会话侧栏（品牌/新建会话/运维中心入口卡/最近会话/用户卡）；运维模式 = 服务中心上下文栏（概览/已接入服务/服务监控/最近活动 + 快捷操作 + 访问策略）。
5. 服务中心首页 + 单服务详情页接**真实 API**，空则显示空态，不伪造数据。
6. 本次范围：**服务中心首页(`/services`) + 单服务详情页(`/services/:id`) + 会话工作台加"运维中心入口卡"**。监控/文档/模型页待后续。
