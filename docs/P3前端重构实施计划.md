# P3 前端整体重构 实施计划

> 状态：**草案，待用户确认后实施。**
> 设计稿：`frontend/参考原型/opermind-deepseek.html`（942 行，DeepSeek 风格三栏工作台）
> 更新：2026-08-02

## 目标

按设计稿整体重构前端：从 antd 6 的粗糙列表式，重做为**自绘 CSS 的三栏式会话工作台**。
后端 API / 数据模型 / P2 工具网关链路全部保留，只重做展示层。

## 技术决策（已与用户确认）

- **React 19 + Vite + Zustand + react-router + react-query 保留**；
- **弃用 antd**（含 @ant-design/icons），改为自绘 CSS；
- 设计 token 用 **CSS 变量**（`:root` + `html[data-theme=...]`），实现 5 主题（钢蓝/雾紫蓝/森林绿/暖琥珀/深夜），存 localStorage；
- 右栏"工作台检查器"照设计稿做弹窗（utility-modal），数据先从现有 API 拿，拿不到的静态占位。

## 工作包（每包前端可摸、独立验收）

### 包 1：三栏壳 + 主题系统
- `App.tsx` 改三栏布局（Sidebar / Workspace / UtilityRail），响应式（三栏→抽屉→移动端）
- CSS 变量 token + 5 主题切换 + localStorage 持久化
- 保留现有路由（会话工作台 / 服务中心）
- **可摸**：三栏骨架 + 换主题

### 包 2：会话主链路
- 欢迎页（问候 + 服务状态 + 4 快捷卡）
- 会话流：用户/助手消息，助手消息嵌 `TraceCard`（消费 tool_invoked，展示工具状态/耗时/脱敏摘要）
- 底部 Composer（发送/附件/安全/上下文 chips/免责声明）
- **可摸**：发一条 SQL 查询，看到完整的助手消息 + 工具调用时间线（P2 数据真实流进来）

### 包 3：左栏 + 右栏 + 弹窗
- Sidebar：新建会话 / 最近会话列表（接会话 API）/ 用户卡
- UtilityRail：服务状态/工作台设置卡 + 当前环境状态 + 弹窗
- ThemeModal：5 主题选择
- **可摸**：新建/切换会话、看右栏弹窗

### 包 4：收尾
- 服务中心页（`ServiceCenterPage`）按新视觉适配（若仍在路由上）
- 删除 antd 依赖，清理 `package.json`
- 全量 `npm run test` + `npm run typecheck` 绿
- **可摸**：整体走一遍，无 antd 残留

## 边界与约束

- 不新增后端改动；P2 工具网关链路原样保留
- 安全规则不变：Trace 只展示脱敏摘要，不展示 CoT/Prompt/敏感原文
- 分工沿用：宽浅样板活（纯展示组件/样式）给牛马；跨层深活（trace 数据流、路由壳）我自己来
- 每个包完成即 Test → Review → Commit，不合并到主分支
