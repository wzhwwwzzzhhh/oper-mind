## 文档治理

- 过时路线、教程、阶段性步骤日志和已被替代的治理记录从工作树删除，避免成为 AI 或开发者的错误上下文；Git 历史负责追溯。
- 不能删除仍在用的代码、测试、公开契约、安全事实或真实验收结论；这些应压缩并迁移到当前基线/工作包文档。
- 新文档只在确有持续决策价值时创建：产品定位放当前治理目录，实施设计/Review/HANDOFF 放对应 `P*-*`，规则放 `开发规范.md`，进度只写 A-Plan。
- 未实现能力必须显示“未启用/不支持”，不允许用 mock 结果伪装成真实服务或监控。
