## 2. 当前不做什么

- 不改 `frontend/`、`report/`、后端 `/api/v1`、数据库、Agent 或运行时资产；
- 不把“自动发现、告警、自动处理”画成已经可用的假能力；
- 不在 V1 加入多人实时协作、成员、共享空间或复杂 RBAC；
- 不把 Investigation/Run、SSE sequence、Trace ID 继续作为普通用户的首要心智模型。
