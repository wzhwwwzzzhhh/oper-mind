# P4.3 Review — 已注册服务中心、有限监控与调查入口

## 1. 产品范围审查

- [x] P4.3 是把已交付的 P4.1/P4.2 放入“服务 → 监控快照 → 会话调查 → 审批执行 → Verify 留痕”的产品入口，不另造 Agent 实验台、监控控制台或第二套 Run 生命周期。
- [x] 首版只有一个代码内注册的 `order-service` 靶场服务；不承诺多服务、用户自行接入、生产配置或 Connector 市场。
- [x] 服务入口创建的是带上下文的 Session，用户点击现有“开始调查”前不产生 Message、Run、Result、Proposal 或外部读取，避免页面跳转被伪装成已经调查。
- [x] `environment_id` / `incident_id` 不被借用为 service 关联；新增 `sessions.service_id` 保持既有字段和未绑定历史会话兼容。

## 2. 读取、监控与真实目标审查

- [x] `PostgresOrdersSlowQueryConnector` 仅复用 P4.1 已审查的固定 health、metrics、目标索引与固定计划读取；页面不直连数据源。
- [x] 快照不调用 `diagnostic-probe`、日志读取、P4.1 investigation executor、故障注入、reset/calibrate 或 P4.2 action executor，因此不会污染性能窗口或产生新的写入能力。
- [x] `disabled` 零外部读取；`mock` 明确为确定性模拟；`target` 失败仅返回受控 unavailable/insufficient 状态，绝不回退 mock 或探测其他资源。
- [x] 服务可用性、数据库状态、性能信号和历史 Verify 已被拆分为确定规则。尤其只有“固定 DB 缺索引 + Seq Scan”与当前服务慢查询/超时事实同时成立时才可显示 `slow_query_detected`；不能把空窗口、部分数据、历史 Verify 或一次 CREATE 成功说成当前正常。
- [x] 所有 target 读取继承 P4.1 的固定靶场、超时、只读、服务器当前库确认和应用元数据库隔离约束；`gongkar`、其他库/端口和生产资源没有读取、回退或写入路径。

## 3. 数据、API 与审计审查

- [x] 显式 Alembic migration 只给 `sessions` 增加 nullable、受限的 `service_id` 与读取索引；无运行时建表、无时序/快照/告警表，避免把一次点查询伪装成可回放监控曲线。
- [x] 通用 `POST /sessions` 不开放 `service_id`，而服务专属 endpoint 先由静态 registry 校验再写入固定值；前端、URL、查询参数均不能伪造目标服务或扩展连接能力。
- [x] 服务活动 read model 只在 `Session(service_id)` 范围内关联 Run、Result、Proposal 和 Verify，按 Run 固定 cursor 排序；未绑定历史会话及其他服务不能混入。
- [x] 公开服务资源和活动摘要只包含脱敏的状态、有限指标、时间和语义结论；不得泄露 SQL、日志、HTTP body、路径、内部 request ID、action digest、连接信息或凭据。
- [x] 不新增服务级 SSE、WebSocket、后台巡检或告警；详情页仅在可见时有限轮询当前快照，异步 action 仍沿用 P4.2 持久化事件读取。

## 4. 实施前必须保持的约束

1. API/迁移前先以本 Design 为准完成 Pydantic、OpenAPI、TypeScript 生成与 API/UI 回归；不能为了页面快速可见而直接读 P4.1 私有对象或在前端拼装健康结论。
2. 服务快照应对 server/database 两个来源分别捕获受控错误，返回安全 source status；不得把下游异常文本写入 API、日志事件或页面。
3. target smoke 只能操作 `opermind_demo` 靶场，并在 finally clean；服务入口生成的 Session、Run、Proposal、Verify 与服务活动关联均需实际断言。
4. 如果实施发现需要用户可写服务配置、凭据、第二个 Connector、监控历史/告警、通用 action 或新的目标连接，立即停止并新建 Design → Review → 用户授权，不得扩写 P4.3。

## 5. 审查结论

P4.3 设计在产品叙事、服务绑定、只读监控、当前/历史事实区分、API/迁移边界、目标隔离和演示验收上通过审查。
