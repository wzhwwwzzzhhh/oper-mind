# 文档知识库页面——知识目录浏览与确定性检索 · PRD

## 背景
P6 已交付知识库第一个切片：**目录内 Markdown 确定性检索**（`knowledge/P6-knowledge-retrieval.md`，完成）——
knowledge 领域 Agent 通过 Tool 在受管目录内按关键词/标题检索 Markdown 文档并返回脱敏摘要，
**但仅作为 Agent 工具接入，无公开 REST API、无前端页面**（P6 PRD「接口：无新增公开 API」）。

前端全局导航（`frontend/src/features/shell/GlobalNav.tsx`）预留了「文档知识库」入口（`docs` 键），
但当前是死占位（`active: false`，点击无路由）——用户无法在页面层面浏览和检索知识文档。

本 PRD 是知识库域的第二个切片：把已交付的确定性检索能力**页面化**——文档知识库页面提供
受管知识目录的文档浏览、页面内检索与文档详情查看，并为此新增知识库 REST API。
知识库的产品边界（`docs/产品定义.md` §6：知识库/文件/RAG/MCP 边界未决策）仍保持：不做 RAG/向量、
不做文档管理写入，本 PRD 只做**受管目录的只读浏览与检索**。

关联：`docs/prd/knowledge/P6-knowledge-retrieval.md`（检索能力与安全边界来源）、
`docs/产品定义.md`（§2.2 知识检索角色、§6 知识库边界）、`docs/路线图.md`（第四阶段"允许目录内
Markdown 知识检索，以及后续知识库能力"）、`docs/开发规范.md`（Connector/Tool 须显式注册、
参数校验、超时、脱敏、权限边界；新增公开 API 须先 Design → Review → 用户确认）。

## 目标
1. 用户能在「文档知识库」页面**浏览**受管知识目录内的 Markdown 文档清单，并查看文档详情内容。
2. 用户在页面内输入检索词，复用 P6 确定性检索能力返回匹配文档与命中片段，无需进入会话即可查阅知识。
3. 全程诚实与安全：未配置/无文档/无匹配如实空态；只读受管目录，凭据文件排除，正文脱敏兜底。

## 用户故事
作为运维工程师，我想打开「文档知识库」页面浏览团队的 SOP/排障记录，直接检索
"kill 慢查询"并点开匹配文档查看正文——以便在开调查会话之前先查存量知识，也能对照文档理解诊断结论。

## 范围

### 做什么
- 新增知识库 REST API（只读）：
  - 文档列表：受管知识目录内的 Markdown 文档清单（相对路径 + 标题）；
  - 检索：按关键词/标题在受管目录内检索，返回匹配文档（标题 + 命中片段）；
  - 文档详情：按文档标识返回受管目录内 Markdown 文档的正文内容（脱敏后）。
- 前端「文档知识库」页面（`/knowledge`，挂载全局导航 `docs` 入口）：
  - 文档列表视图（空态诚实：未配置/无文档）；
  - 页面内检索框 + 结果列表（无匹配诚实空态）；
  - 文档详情视图（展示受管目录内 Markdown 正文）。
- 复用 P6 已交付的确定性检索能力与安全边界（受管目录判定、凭据文件排除、脱敏兜底）。

### 不做什么（明确排除）
- 不做文档上传 / 编辑 / 删除 / 管理（只读浏览，写能力不在本 PRD）。
- 不做向量数据库 / Embedding / RAG / 语义检索（后续阶段，需单独 Design）。
- 不接入外部知识源（网站、Confluence、工单系统等）。
- 不展示受管目录外的文件或路径；不授予任意文件系统访问。
- 不展示非 Markdown 文件 / 二进制文件。
- 不将凭据文件（`.env`、`config.local.yaml`、含 `sk-` 内容）纳入列表、检索或详情。
- 不做知识目录配置管理界面（目录路径仍由配置/环境变量提供，沿用 P6 方案）。
- 不改 mock 数据源（`data/mock_db.py`、`data/scenarios.py`）与 S1–S4 评测路径。

## 功能需求

### 1. 文档列表
- **输入**：无（或分页参数，Design 定）。
- **行为**：读取受管知识目录内全部 Markdown 文档，返回文档清单（相对路径、标题）；
  目录未配置/不存在 → "未配置"；目录内无 Markdown → "无文档"。
- **输出**：文档清单（诚实空态）；清单不含凭据文件。

### 2. 页面内检索
- **输入**：检索词（参数校验：长度限制、拒绝路径注入字符，沿用 P6 校验）。
- **行为**：复用 P6 确定性检索能力，在受管文档中按标题与正文关键词匹配，返回匹配文档的
  标题 + 命中片段，按相关度排序，限制返回条数；无匹配 → "无匹配文档"。
- **输出**：匹配文档列表（含命中片段）；检索来源标注为受管知识目录。

### 3. 文档详情
- **输入**：文档标识（受管目录内的相对路径，参数校验防路径逃逸）。
- **行为**：返回该文档的正文内容（脱敏兜底后）；仅限受管目录内 Markdown 文档；
  目录外路径/凭据文件被拒绝。
- **输出**：文档正文（脱敏后）；不返回目录外内容与凭据。

### 4. 前端「文档知识库」页面
- **输入**：全局导航 `docs` 入口 → 路由 `/knowledge`。
- **行为**：
  - 页面加载文档列表，展示文档清单（标题 + 相对路径），点击进入详情；
  - 页面提供检索框，输入检索词展示检索结果，结果项可点击进入详情；
  - 未配置/无文档/无匹配/请求失败均展示对应诚实空态，不伪造；
  - 页面标注数据来源（"受管知识目录 · 只读"）。
- **输出**：文档列表 / 检索结果 / 文档详情 三个视图。

## 非功能需求
- **性能**：列表与详情接口限时（复用网关超时模式）；检索限时与条数受限（沿用 P6）。
- **安全**：只读受管目录；参数校验防路径逃逸；凭据文件排除；正文脱敏兜底；
  文档标识不得暴露受管目录外路径。
- **可靠**：未配置/目录空/无匹配/请求失败均诚实降级，不抛异常、不崩溃。
- **诚实**：数据来源标注"受管知识目录 · 只读"；不把目录浏览伪装成数据库查询或实时监控。

## 数据与接口影响
- 数据：无新增持久化（即时读取受管目录，不建索引表、不存文档副本）。
- 接口：**新增知识库 REST API**（文档列表 / 检索 / 文档详情，只读）；既有接口契约不变。
  文档详情接口**显式扩展 P6 的"全文不暴露前端"边界**——仅限受管目录内 Markdown 正文可读，
  仍排除凭据文件与脱敏兜底（该扩展须经 Design 确认）。

## 验收标准
- [ ] AC1: 当知识目录未配置或不存在时，列表接口返回"未配置"状态，页面显示"未配置"诚实空态，不崩溃、不伪造。
- [ ] AC2: 当知识目录为空（无 Markdown 文档）时，列表接口返回"无文档"状态，页面显示"暂无文档"。
- [ ] AC3: 当目录存在文档时，列表接口返回受管文档清单（标题 + 相对路径），页面可渲染列表并进入详情。
- [ ] AC4: 页面内检索：当检索词有匹配时，返回匹配文档（标题 + 命中片段）按相关度排序且条数受限；
      无匹配时显示"无匹配文档"诚实空态。
- [ ] AC5: 文档详情仅返回受管目录内 Markdown 正文（脱敏后）；目录外路径/路径逃逸输入被拒绝，
      不返回目录外文件。
- [ ] AC6: 凭据文件（`.env`、`config.local.yaml`、含 `sk-` 内容）不出现在列表、检索结果与详情中。
- [ ] AC7: 详情正文经脱敏兜底，不包含凭据/连接串。
- [ ] AC8: 全局导航「文档知识库」入口可访问 `/knowledge`，页面标注"受管知识目录 · 只读"。
- [ ] AC9: 请求失败（后端不可用等）时页面显示失败空态，可重试，不崩溃。
- [ ] AC10: 回归 —— mock 评测（S1–S4）路径不受影响；P6 检索工具行为不变；
       既有后端测试、前端 typecheck/test/build（如涉及）全绿。

## 边界与约束
- 安全边界：只读受管目录；参数校验防路径逃逸；凭据文件排除；正文脱敏兜底；
  知识目录路径仍由配置/环境变量提供（沿用 P6 `OPERMIND_KNOWLEDGE_DIR` 方案），不新增凭据。
- 降级策略：未配置 → "未配置"；目录空 → "无文档"；无匹配 → "无匹配文档"；
  请求失败 → 失败空态可重试；均不抛异常、不伪造。
- 兼容性：P6 检索工具与 mock 评测行为不变；既有接口契约不变。
- 工程闸门：本 PRD 涉及**新增公开 REST API 与前端页面**，按开发规范须先 Design → Review →
  用户确认才能实施；本 PRD 是需求层，不替代 Design 文档。

  正文可读——渲染方式（Markdown 渲染/纯文本）与脱敏粒度须 Design 定。
