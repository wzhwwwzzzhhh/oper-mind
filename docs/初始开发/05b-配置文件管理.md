# 05b 配置文件管理：安全存储 API Key

---

## 目标

将 API Key 从代码中抽离到配置文件，避免敏感信息泄露，同时支持不同环境（开发/生产）使用不同配置。

---

## 前置依赖

- [x] 已完成 Phase 1-5，有需要配置 API Key 的地方

---

## 知识点：为什么不能把 API Key 写死在代码里？

| 问题      | 后果                      |
| ------- | ----------------------- |
| 提交到 git | 公开仓库所有人都能看到你的 Key       |
| 多人协作    | 每个人的 Key 不同，代码改来改去      |
| 环境切换    | 开发用 mock，生产用真实 Key，要改代码 |

**核心原则：** 代码和配置分离。代码管"怎么跑"，配置管"跑在哪里"。

---

## 步骤

### 1. 安装 PyYAML

```bash
pip install pyyaml
```

YAML 是 Python 解析 YAML 文件的标准库，类似 Java 处理 YAML 的 SnakeYAML。

### 2. 创建配置目录和模板文件

项目根目录下：

```
oper-mind/
├── config/
│   ├── config.example.yaml    ← 模板，提交到 git
│   └── config.local.yaml      ← 真实配置，被 .gitignore 屏蔽
```

文件：`config/config.example.yaml`

```yaml
# 配置模板：复制此文件为 config.local.yaml，填入真实值
llm:
  api_key: "your-api-key-here"   # 你的 API Key
  base_url: "https://api.deepseek.com"
  model: "deepseek-chat"         # 模型名称
```

文件：`config/config.local.yaml`

```yaml
llm:
  api_key: "sk-xxxxx"           # 真实 Key
  base_url: "https://api.deepseek.com"
  model: "deepseek-chat"
```

**知识点：YAML 基础**

| 概念  | 说明                    | 示例                              |
| --- | --------------------- | ------------------------------- |
| 键值对 | `key: value`，冒号后面要加空格 | `api_key: "sk-xxx"`             |
| 缩进  | 用空格表示层级，**不能用 tab**   | 两个空格缩进                          |
| 字符串 | 可以加引号，也可以不加           | `name: "hello"` 或 `name: hello` |
| 注释  | `#` 开头                | `# 这是注释`                        |

### 3. 配置 .gitignore

在 `.gitignore` 中添加：

```
# 本地配置文件（包含敏感信息）
config/config.local.yaml
```

这样 `config.local.yaml` 永远不会被提交到 git。

`config.example.yaml` 提交到 git，方便其他开发者知道需要配什么。

**这就是 Spring 的套路：** `application.yml`（默认配置）提交 git，`application-local.yml`（本地覆盖）被 gitignore。

### 4. 编写配置加载函数

新建文件：`src/config.py`

```python
"""配置管理：从 YAML 文件加载配置"""

import yaml
import os


def load_config() -> dict:
    """
    加载配置，优先加载本地配置。

    加载顺序：
    1. config/config.local.yaml（如果有）
    2. config/config.example.yaml（fallback）

    如果两个文件都不存在，报错。
    这样本地开发者只需要配 local 文件，只改自己要改的字段。
    """
    config_dir = os.path.join(os.path.dirname(__file__), "..", "config")

    # 先尝试加载 local
    local_path = os.path.join(config_dir, "config.local.yaml")
    if os.path.exists(local_path):
        with open(local_path, "r", encoding="utf-8") as f:
            return yaml.safe_load(f)

    # fallback 到 example
    example_path = os.path.join(config_dir, "config.example.yaml")
    if os.path.exists(example_path):
        with open(example_path, "r", encoding="utf-8") as f:
            return yaml.safe_load(f)

    raise FileNotFoundError(
        "找不到配置文件！\n"
        f"请创建 {local_path}\n"
        f"参考 {example_path} 填写你的 API Key"
    )
```

**知识点：**

| 概念               | 说明                                        |
| ---------------- | ----------------------------------------- |
| 文件优先级            | local 优先于 example，和 Spring 的 profile 机制一样 |
| fallback         | example 作为兜底，保证即使没有 local 也不会直接崩溃         |
| `os.path.join`   | 跨平台的路径拼接，Windows 用 `\\`，Linux/mac 用 `/`   |
| `yaml.safe_load` | 安全的 YAML 加载器，不会执行 YAML 中的任意代码             |

### 5. 改造 main.py

```python
"""CLI 入口"""

from src.core.llm import LLMClient
from src.core.tool_registry import ToolRegistry
from src.core.agent import Agent
from src.tools.db_tools import ExplainTool, ShowCreateTableTool, ShowIndexTool
from src.scenarios.db_diagnosis import SYSTEM_PROMPT, TOOL_CALLING_EXAMPLE
from src.config import load_config


def build_agent() -> Agent:
    """从配置文件读取 API 配置，构造 Agent"""
    config = load_config()
    llm_config = config["llm"]

    llm = LLMClient(
        api_key=llm_config["api_key"],
        base_url=llm_config["base_url"],
        model=llm_config.get("model", "deepseek-chat"),
    )

    tools = ToolRegistry()
    tools.register(ExplainTool())
    tools.register(ShowCreateTableTool())
    tools.register(ShowIndexTool())

    system_prompt = SYSTEM_PROMPT
    system_prompt += TOOL_CALLING_EXAMPLE

    return Agent(llm=llm, tools=tools, system_prompt=system_prompt)


def main():
    agent = build_agent()

    print("=" * 50)
    print("数据库诊断 Agent 已启动")
    print("输入 SQL 语句进行分析，输入 'exit' 退出")
    print("测试用例：")
    print("  1. SELECT * FROM orders WHERE status = 'PENDING'")
    print("  2. SELECT * FROM orders ORDER BY create_time DESC")
    print("=" * 50)

    while True:
        user_input = input("\n> ").strip()
        if user_input.lower() in ("exit", "quit", "q"):
            break

        result = agent.run(user_input)
        print(f"\n{result}")


if __name__ == "__main__":
    main()
```

**改造要点：**

| 改了什么                 | 为什么                                                    |
| -------------------- | ------------------------------------------------------ |
| 去掉硬编码的 API Key       | 现在从 YAML 读取                                            |
| `build_agent()` 不用传参 | 自己读配置，调用方不需要关心                                         |
| `model` 有默认值         | `llm_config.get("model", "deepseek-chat")`，即使例子里没写也不报错 |

## 扩展：支持多环境

当你需要区分开发/测试/生产环境时，可以用不同文件：

```
config/
  config.dev.yaml       # 开发环境（mock 模式）
  config.staging.yaml   # 测试环境
  config.prod.yaml      # 生产环境（真实 Key）
```

然后在 `load_config()` 中根据环境变量选择加载哪个：

```python
import os

env = os.getenv("APP_ENV", "dev")
# 加载 config.{env}.yaml
```

跟 Spring 的 `spring.profiles.active=dev` 一模一样。
