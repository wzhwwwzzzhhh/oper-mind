## 读图要点

- 前端、产品控制、执行装配、图运行与资源访问各有职责，业务模块通过能力注册进入执行链。
- LangGraph 是 V1 已有起点；create_agent、官方 middleware 与 Deep Agents 都是尚待兼容验证的组件候选。
- 自有层维护产品契约并复用 V1 会话、模型、Run、ToolGateway 等资产；不是再写一个完整框架。

图中的装配与通用执行是目标职责，并未完成 V2 实施。Run / 审批 / 权限的业务事实不会因采用框架而改由图状态或 checkpoint 决定。

## 可编辑的结构源图

```mermaid
flowchart TB
    UI["前端：会话 / Agent / 能力 / 任务结果<br/>V1 交互已有，V2 信息架构适配"]
    APP["产品控制：会话 / 模型 / Run / 审计<br/>V1 资产复用"]
    DEF["装配契约：Agent 定义 / 能力注册 / 上下文<br/>V2 待建设"]
    RUNTIME["统一 Agent 执行机制<br/>现有领域 ReAct 起点需适配"]
    LG["LangGraph：图、子图、编排<br/>V1 已有"]
    OFF["create_agent / middleware / Deep Agents<br/>候选：兼容后择需采用"]
    GW["ToolGateway<br/>V1 已有：执行资格由程序校验"]
    CONN["Connector / 资源绑定<br/>运维已有，新业务扩展"]
    UI --> APP --> DEF --> RUNTIME
    LG -. 提供运行机制 .-> RUNTIME
    OFF -. 提供可复用组件 .-> RUNTIME
    RUNTIME --> GW --> CONN
```

Mermaid 与 SVG 展示同一组职责；SVG 简化部分返回线以保持可读性，以明确的边界说明为准。修改结构时需同步源图、SVG 与 PNG 预览。
