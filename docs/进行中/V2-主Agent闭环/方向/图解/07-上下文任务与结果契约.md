## 读图要点

- Agent 定义、能力声明和已编译执行结构可以在满足隔离条件后复用；消息、观察与本次调用记录按执行管理。
- 本次装配固定模型与能力版本，以及选定输入引用。任务需要什么才加载什么，大结果使用受控产物引用。
- LangGraph state / checkpoint 管理运行过程；应用层负责任务归属、结果接纳和产品事件，不能互相替代。

这些是拟议职责和契约，不是已存在的 API / 数据库字段。当前 Agent 实例持有可变历史；缓存复用图之前必须先消除状态串线。原始大结果的存储、保留和读取范围需独立确定。

## 可编辑的结构源图

```mermaid
flowchart TB
    CONFIG["可复用定义：职责 / 模型配置 / 能力版本"] --> SNAP["本次装配快照：模型绑定 / 能力版本 / 允许资源"]
    INPUT["用户消息 / 已选择证据与历史"] --> CONTEXT["本次上下文：裁剪、按范围引用"]
    SNAP --> EXEC["一次执行：独立消息 / 观察 / 调用记录"]
    CONTEXT --> EXEC
    EXEC --> GRAPH["LangGraph State / 可选 Checkpoint<br/>技术运行状态"]
    EXEC --> SIGNAL["结果或事件候选"]
    SIGNAL --> APP["应用层校验与接纳<br/>任务归属 / 终态 / 产品事件"]
    APP --> OUTPUT["TaskResult：状态 / 摘要 / 数据 / Artifact 引用"]
    OUTPUT --> UI["安全投影 → 会话展示"]
```

Mermaid 与 SVG 展示同一组职责；SVG 简化部分返回线以保持可读性，以明确的边界说明为准。修改结构时需同步源图、SVG 与 PNG 预览。
