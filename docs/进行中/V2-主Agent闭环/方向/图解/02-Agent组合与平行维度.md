## 读图要点

- 四种组合共用底座，既不是四套运行时，也不是从低到高的升级路线。
- 基础主 Agent 可以按需挂技能 / 能力；任务复杂度与隔离需求决定是否委派子任务。
- 业务独立性决定是否由多个主 Agent 协作；一个业务主 Agent 也可以挂能力、派子 Agent。

四种组合是目标使用方式。V1 有领域角色与诊断编排资产，不能直接视为这些通用装配和协作机制已经实现。

## 可编辑的结构源图

```mermaid
flowchart LR
    BASE["共享底座：执行机制 / 能力注册 / 任务契约 / 网关"]
    ONE["单主 Agent<br/>自己完成任务"]
    PACK["主 Agent + 技能 / 能力包<br/>按需扩展能力"]
    TASK["任务维度：主 Agent → 子 Agent<br/>父任务负责汇总与交付"]
    BIZ["业务维度：主 Agent ↔ 主 Agent<br/>独立业务责任，按需请求结果"]
    BASE --> ONE
    BASE --> PACK
    BASE --> TASK
    BASE --> BIZ
```
