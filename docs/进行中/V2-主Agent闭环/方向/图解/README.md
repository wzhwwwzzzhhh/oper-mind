## 如何阅读

每张图只回答一个问题，配有 PNG 预览、可缩放 SVG、读图要点与可编辑 Mermaid。概念之间的关系、一次执行的步骤和当前建设状态分别展示。

- **先看全貌**：01 分层 → 02 组合 → 08 现状与建设顺序。
- **理解单次执行**：03 主循环 → 04 能力包 → 07 上下文与任务结果。
- **理解协作**：05 子任务委派 → 06 独立业务主 Agent 协作；二者平行，可同时组合。

## 统一状态与边界

- **已有 / 复用**：V1 有代码与历史交付依据，迁移到 V2 仍需适配和验证。
- **适配**：已有起点，但诊断语义、执行状态或页面职责需要调整。
- **待建设**：V2 目标机制与契约，尚未实施。
- **候选**：LangChain / Deep Agents 官方组件尚未通过兼容验证，不代表已采用。
- **后置**：完整 Recovery、分布式调度、跨进程协议、长期记忆、编辑器等按实际需求立项。

箭头表示对应图的调用、结果、依赖或配置关系，具体含义由该图的标题与说明限定。实线不代表功能已经实现。图 05 / 06 的时序只表达目标协议，不预设同步网络调用、固定 API 或数据库字段。

主 Agent 是基本执行单元，能力挂载、子任务委派、独立主 Agent 协作可组合。语义选择由模型作结构化判断；资格校验、权限、预算与执行状态仍由程序负责。所有资源访问都走受控后端，不因换成框架组件而自动获得更多执行能力。

图 03 简化了失败与恢复分支，图 04 以文档差异作为拟议样例；两者都不能替代正式 PRD 和 Design。新增商业业务仍需要用户、数据源与效果验证。
