## 这是什么

V2 是 OperMind 的目标形态，替换 V1。V1 保留为过渡基线：首切片不删除 V1；V2 达到能力对等后，V1 调查入口与 Coordinator 路径逐步下线。

一句话：**主 Agent 用 ReAct 循环执行；所有外部能力收口到一份 Capability 契约；子 Agent 和多主 Agent 是按需启用的协作轴。**

- **一个契约**：Capability 是主 Agent 唯一看到的能力单元，内部装 Skill、Tool 或 Workflow。知识型能力只装 Skill；执行型能力装 Tool/Workflow，可能绑定外部资源。
- **一条执行轴**：直答 → 知识型能力 → 执行型能力 → ReAct 多轮（决策 → 工具 → 观察 → 再决策）。
- **两条协作轴**：子 Agent 委派解决上下文隔离与长任务；多主 Agent 协作解决业务独立性。两者平行，不默认启用。

首闭环（`text.literal_compare@1`）是一次性决策图，用来验证 Run 接缝和安全投影；它不是 V2 的目标执行形态。
