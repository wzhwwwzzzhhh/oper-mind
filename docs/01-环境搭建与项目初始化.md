# 01 环境搭建与项目初始化

---

## 目标

搭好 Python 开发环境、初始化 Git 仓库、建好目录结构，确保你跑得起来一个 Hello World。

---

## 前置依赖

- 你的电脑上装了 Python 3.10+（推荐 3.11）
- 你的电脑上装了 Git

---

## 步骤

### 1. 确认 Python 版本

```bash
python --version
```

如果输出版本号低于 3.10，去 python.org 下载安装 3.11+。

### 2. 创建虚拟环境

虚拟环境是 Python 项目的"隔离区"，每个项目有自己的依赖，互不干扰。

```bash
# 在 db-agent 目录下执行
cd D:/market-handsome/newproject/db-agent
python -m venv .venv
```

**知识点**：`.venv` 是虚拟环境目录名。激活后，你用 `pip install` 装的包只在这个项目里生效，不会污染全局。

### 3. 激活虚拟环境

```bash
# Windows
.venv\Scripts\activate

# Mac / Linux
source .venv/bin/activate
```

激活后命令行前面会出现 `(.venv)` 前缀。

安装了 Git Bash 也可以用 Windows 的命令。

### 4. 安装依赖

创建 `requirements.txt` 文件：

```txt
# 核心依赖
openai>=1.0.0

# Web 框架（最后阶段才用，先装好放着）
fastapi>=0.110.0
uvicorn>=0.27.0

# LangGraph（第8阶段才用，先装好）
langgraph>=0.4.0
langchain-openai>=0.3.0
```

安装：

```bash
pip install -r requirements.txt
```

**知识点**：`requirements.txt` 是 Python 项目的依赖清单。别人 clone 项目后执行 `pip install -r requirements.txt` 就能装好所有依赖。

### 5. 验证安装

```bash
python -c "from openai import OpenAI; print('openai ok')"
python -c "import fastapi; print('fastapi ok')"
python -c "import langgraph; print('langgraph ok')"
```

三条都输出 `ok` 就对了。

### 6. 初始化 Git

```bash
git init
```

### 7. 创建 .gitignore

创建 `.gitignore` 文件：

```gitignore
# 虚拟环境
.venv/

# Python 缓存
__pycache__/
*.pyc
*.pyo

# 环境变量
.env

# IDE
.idea/
.vscode/

# OS
.DS_Store
Thumbs.db

# 测试数据
data/__pycache__/
```

### 8. 确认目录结构

跑一下这个命令看目录结构对不对：

```bash
ls -R
```

应该看到这样的结构：

```
db-agent/
├── .gitignore
├── requirements.txt
├── docs/
│   └── 01-环境搭建与项目初始化.md
├── src/
│   ├── core/
│   ├── tools/
│   ├── memory/
│   └── scenarios/
├── data/
└── tests/
```

### 9. 首次提交

```bash
git add .
git commit -m "feat: 初始化项目结构"
```

## 你会用到的知识点

| 概念 | 说明 |
|------|------|
| 虚拟环境 venv | Python 项目的隔离运行环境 |
| requirements.txt | 依赖清单，别人能一键安装 |
| .gitignore | Git 忽略规则，不提交垃圾文件 |

## 常见问题

**Q: pip 下载太慢怎么办？**
A: 可以设置国内镜像源：
```bash
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
```

**Q: 激活虚拟环境报错 "execution policy"？**
A: 以管理员身份运行 PowerShell，执行 `Set-ExecutionPolicy Unrestricted`。或者在 Git Bash 里操作。

**Q: 下次打开终端还要重新激活吗？**
A: 是的，每次打开新终端都要执行 `.venv\Scripts\activate`。
