# 能力装配、上下文与框架候选

> 核验日期：2026-10-12。资料入口与核验边界见[学习目录](../README.md)。
> 共 14 项；“先学 / 按需学 / 进阶”表示建议顺序，不是开发门禁。

这一组用于判断哪些通用机制可以借用。LangChain / Deep Agents 的概念与我们拟定的 Capability 不应强行一一对应；学习与评估不代表已引入依赖，也不授权文件、网络或执行权限。

<a id="a01"></a>

## A01 · LangChain overview

- 官方入口：[LangChain overview](https://docs.langchain.com/oss/python/langchain/overview)
- 形式／优先级：官方文档；按需学。
- 重点看：框架定位、Agent 与集成入口。
- 对应疑问：LangChain 和 LangGraph 分别承担哪一层？

<a id="a02"></a>

## A02 · Agents

- 官方入口：[Agents](https://docs.langchain.com/oss/python/langchain/agents)
- 形式／优先级：官方文档；先学。
- 重点看：create_agent、模型、工具、动态上下文和执行循环。
- 对应疑问：能否复用现成主循环，同时保留模型配置与 ToolGateway？

<a id="a03"></a>

## A03 · Models

- 官方入口：[Models](https://docs.langchain.com/oss/python/langchain/models)
- 形式／优先级：官方文档；按需学。
- 重点看：模型调用接口、工具绑定与输出行为。
- 对应疑问：模型适配层能提供什么，哪些语义仍受具体提供方影响？

<a id="a04"></a>

## A04 · Tools

- 官方入口：[Tools](https://docs.langchain.com/oss/python/langchain/tools)
- 形式／优先级：官方文档；先学。
- 重点看：工具 schema、参数、结果与运行上下文。
- 对应疑问：模型可调用的工具定义和真正受控的后端执行如何衔接？
- 使用边界：工具装饰器或工具 schema 不等于我们的执行网关；不能绕过权限、脱敏、超时和审计。

<a id="a05"></a>

## A05 · Structured output

- 官方入口：[Structured output](https://docs.langchain.com/oss/python/langchain/structured-output)
- 形式／优先级：官方文档；先学。
- 重点看：结构化结果 schema、模型支持差异、验证与错误处理。
- 对应疑问：一次语义决策怎样返回可检查的能力选择或追问信息？
- 使用边界：结构化输出不保证语义正确；无效、不可用、越权或预算超限仍需确定性处理。

<a id="a06"></a>

## A06 · Short-term memory

- 官方入口：[Short-term memory](https://docs.langchain.com/oss/python/langchain/short-term-memory)
- 形式／优先级：官方文档；按需学。
- 重点看：会话状态、保留、裁剪和摘要。
- 对应疑问：持续聊天时，哪些信息保留，哪些可以压缩？

<a id="a07"></a>

## A07 · Context engineering

- 官方入口：[Context engineering](https://docs.langchain.com/oss/python/langchain/context-engineering)
- 形式／优先级：官方文档；按需学。
- 重点看：模型上下文、工具上下文与可用信息的组织。
- 对应疑问：隔离上下文不是简单删消息，那到底需要控制哪些信息？

<a id="a08"></a>

## A08 · Middleware overview

- 官方入口：[Middleware overview](https://docs.langchain.com/oss/python/langchain/middleware/overview)
- 形式／优先级：官方文档；按需学。
- 重点看：Agent 执行接缝与中间件职责。
- 对应疑问：通用策略怎样插入循环，而不把业务判断写死到内核？

<a id="a09"></a>

## A09 · Prebuilt middleware

- 官方入口：[Prebuilt middleware](https://docs.langchain.com/oss/python/langchain/middleware/built-in)
- 形式／优先级：官方文档；按需学。
- 重点看：按需查摘要、调用限制、重试与人工介入等条目，核对各自参数及版本。
- 对应疑问：哪些机制可以配置复用，哪些需要适配或自写？
- 使用边界：选用前核对当前依赖和异常语义；官方 HITL 不代替已有审批与执行安全边界。

<a id="a10"></a>

## A10 · Deep Agents overview

- 官方入口：[Deep Agents overview](https://docs.langchain.com/oss/python/deepagents/overview)
- 形式／优先级：官方文档；按需学。
- 重点看：长任务、规划、文件系统与子 Agent 等能力的整体组织。
- 对应疑问：Deep Agents 是否适合成为主 Agent 的候选实现？
- 使用边界：这是选型问题，不预设替换现有运行接口；默认工具和执行环境必须单独评估。

<a id="a11"></a>

## A11 · Deep Agents Skills

- 官方入口：[Deep Agents Skills](https://docs.langchain.com/oss/python/deepagents/skills)
- 形式／优先级：官方文档；按需学。
- 重点看：Skill 的格式、发现与按需加载。
- 对应疑问：技能包如何提供指引，而不是被误当成执行权限？
- 使用边界：Skill 不等于我们的完整 Capability；任务输入输出、权限和完成条件另有应用层契约。

<a id="a12"></a>

## A12 · Deep Agents Subagents

- 官方入口：[Deep Agents Subagents](https://docs.langchain.com/oss/python/deepagents/subagents)
- 形式／优先级：官方文档；按需学。
- 重点看：子 Agent 配置、委派和上下文边界。
- 对应疑问：官方委派机制怎样与父子 Run、取消和成本记录接起来？

<a id="a13"></a>

## A13 · Deep Agents Backends

- 官方入口：[Deep Agents Backends](https://docs.langchain.com/oss/python/deepagents/backends)
- 形式／优先级：官方文档；进阶。
- 重点看：文件／状态存储后端的用途和边界。
- 对应疑问：不同存储后端如何改变数据生命周期与隔离范围？
- 使用边界：学习不授权访问本机任意路径、云存储或真实服务；沙箱与路径权限另行确认。

<a id="a14"></a>

## A14 · Deep Agents Profiles

- 官方入口：[Deep Agents Profiles](https://docs.langchain.com/oss/python/deepagents/profiles)
- 形式／优先级：官方文档；进阶。
- 重点看：按当前官方说明了解 Agent 配置组织及其状态。
- 对应疑问：配置和代码如何一起表达一个 Agent 的装配？
- 使用边界：版本敏感的候选资料，不作为本项目能力包格式已定稿的依据。
