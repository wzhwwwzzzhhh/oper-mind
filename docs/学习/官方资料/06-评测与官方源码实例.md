# 评测与官方源码实例

> 核验日期：2026-10-12。资料入口与核验边界见[学习目录](../README.md)。
> 共 9 项；“先学 / 按需学 / 进阶”表示建议顺序，不是开发门禁。

资料帮助我们学习验证方法与实现接缝，不用 GitHub 星数或厂商宣传替代业务需求和效果评测。源码条目已核验官方仓库入口，本次没有完整审查或运行这些项目。

<a id="e01"></a>

## E01 · Test agents

- 官方入口：[Test agents](https://docs.langchain.com/oss/python/langchain/test)
- 形式／优先级：官方测试文档；先学。
- 重点看：确定性测试、模型／工具替身与集成验证的组织。
- 对应疑问：怎样测试路由、工具失败、状态和交付，而不只看最终文本？

<a id="e02"></a>

## E02 · LangSmith Evaluation

- 官方入口：[LangSmith Evaluation](https://docs.langchain.com/langsmith/evaluation)
- 形式／优先级：官方文档；按需学。
- 重点看：数据集、评测器、离线实验和比较。
- 对应疑问：怎样在同一任务集上比较单 Agent 与协作方案？
- 使用边界：质量、延迟、成本与失败率分别记录；不要把更多 Agent 当作成功条件。

<a id="e03"></a>

## E03 · LangSmith Observability

- 官方入口：[LangSmith Observability](https://docs.langchain.com/langsmith/observability)
- 形式／优先级：官方文档；按需学。
- 重点看：Trace、运行关联与故障定位。
- 对应疑问：怎样看见发生了什么，同时保留证据与隐私边界？
- 使用边界：采用外部追踪前必须检查数据出境与脱敏；学习不授权上传 Prompt、CoT、原始工具输出或凭据。

## E04 · langchain-ai/langchain-academy

- 官方入口：[langchain-ai/langchain-academy](https://github.com/langchain-ai/langchain-academy)
- 形式／优先级：官方课程源码；先学。
- 重点看：对照课程章节查 Notebook 和示例；先跟踪 State、节点输入输出，再选择最小练习。
- 对应疑问：视频里的概念对应哪一段代码？
- 使用边界：示例可能要求账号、模型调用或外部服务；先阅读、检查配置与权限，本次未执行。

## E05 · langchain-ai/langgraph

- 官方入口：[langchain-ai/langgraph](https://github.com/langchain-ai/langgraph)
- 形式／优先级：官方框架源码／示例入口；按需学。

## E08 · langchain-ai/open_deep_research

- 官方入口：[langchain-ai/open_deep_research](https://github.com/langchain-ai/open_deep_research)
- 形式／优先级：官方端到端示例；进阶。
- 重点看：与 C06 配套，观察状态、任务分解、汇总和评测组织。

## E09 · langchain-ai/agent-chat-ui

- 官方入口：[langchain-ai/agent-chat-ui](https://github.com/langchain-ai/agent-chat-ui)
- 形式／优先级：官方前端参考实现；进阶。
- 重点看：交互、流式状态和 Agent 后端接缝。
- 对应疑问：现有前端重构时，有哪些交互组织方式可以借鉴？
- 使用边界：不是已决定替换的前端；后端协议、认证、脱敏和现有组件兼容仍需单独设计。
