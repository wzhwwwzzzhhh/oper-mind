# 官方课程与视频

> 核验日期：2026-10-12。资料入口与核验边界见[学习目录](../README.md)。
> 共 13 项；“先学 / 按需学 / 进阶”表示建议顺序，不是开发门禁。

优先使用 LangChain Academy 的课程目录定位视频、讲义与配套练习。先选章节，再按疑问补课；不要为了完成课程进度而暂停整个项目。

<a id="c01"></a>

## C01 · Quickstart: LangGraph Essentials – Python

- 官方入口：[Quickstart: LangGraph Essentials – Python](https://academy.langchain.com/courses/langgraph-essentials-python)
- 形式／优先级：视频课程；先学。
- 重点看：Nodes、Edges、Conditional Edges、Memory、Interrupt/HITL。
- 对应疑问：图、节点、状态和 Agent 循环分别负责什么？

<a id="c02"></a>

## C02 · Introduction to LangGraph – Python

- 官方入口：[Introduction to LangGraph – Python](https://academy.langchain.com/courses/intro-to-langgraph)
- 形式／优先级：视频课程＋章节资料；先学。
- 重点看：先看 Module 1；契约看 Module 2 的 State Schema、State Reducers、Multiple Schemas；并发看 Module 4 的 Parallelization、Sub-graphs、Map-reduce。Module 3、5、6 按需补。
- 对应疑问：如何从简单图走到状态、并行分支和子图，而不混淆这些概念？

## C04 · Introduction to LangChain – Python

- 官方入口：[Introduction to LangChain – Python](https://academy.langchain.com/courses/foundation-introduction-to-langchain-python)

- 重点看：Module 1 的 Agent/Tools/Memory；Module 2 的上下文、状态与多 Agent；Module 3 的 Middleware 和 HITL。
- 对应疑问：使用现成 Agent 循环后，哪些接缝仍需我们控制？

<a id="c05"></a>

## C05 · Introduction to Deep Agents

- 官方入口：[Introduction to Deep Agents](https://academy.langchain.com/courses/foundation-introduction-to-deepagents)
- 形式／优先级：视频课程；按需学。
- 重点看：先看 Module 1 的基础与 Threads/Checkpointers；再看 Module 3 的 Summarization and Offload、Skills、Memory，以及 Module 4 的 Delegation/Subagents。
- 对应疑问：技能加载、上下文卸载和子任务委派是否可以复用官方实现？
- 使用边界：Deep Agents 是待验证候选，课程中的文件系统、沙箱与工具权限不自动成为 OperMind 已批准能力。

<a id="c06"></a>

## C06 · Project: Deep Research with LangGraph

- 官方入口：[Project: Deep Research with LangGraph](https://academy.langchain.com/courses/deep-research-with-langgraph)
- 形式／优先级：项目课程；进阶。
- 重点看：研究任务的拆分、收集、汇总与评测；对照官方 open_deep_research 仓库。
- 对应疑问：怎样研究一个完整工作流的状态和协作边界？
- 使用边界：只借鉴实现与验证方法，不因此选定研究业务，也不证明多 Agent 在所有任务上更好。

<a id="c07"></a>

## C07 · Project: Ambient Agents with LangGraph

- 官方入口：[Project: Ambient Agents with LangGraph](https://academy.langchain.com/courses/ambient-agents)
- 形式／优先级：项目课程；进阶。
- 重点看：邮件示例中的任务触发、人工介入和评测设计。
- 对应疑问：不只是聊天时，Agent 的触发与人工干预该怎样表达？
- 使用边界：邮件是教学案例；不授权接入邮箱、发送邮件或自动执行任何真实动作。
