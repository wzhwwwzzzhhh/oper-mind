# OperMind 当前文档

本目录只保留当前正式产品需要的最小事实源：

| 文件 | 作用 |
|---|---|
| `产品定义.md` | 产品定位、用户体验、模块边界与当前未决问题。 |
| `路线图.md` | 当前工作方向和开始下一实现前必须完成的设计。 |
| `开发规范.md` | 前后端、Agent、Tool、凭据、安全和提交规则。 |

## 文档使用规则

- 这三份文件是当前需求与开发规则的唯一文档来源。
- 当前代码是已有技术资产，不自动等同于新的产品规格。
- 已删除的旧工作包、靶场、验收、Review、Handoff 和路线图不应从 Git 历史恢复为当前上下文。
- 任何重大产品、数据模型、凭据、Connector、监控、权限、执行或外部连接决策，必须先补充到这里的当前文档，再进入实现。
