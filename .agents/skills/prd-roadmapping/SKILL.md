# 方向规划链（OperMind 项目专属）

## 核心原则
方向是产品决策，**由用户拍板**；这个 skill 负责把"候选需求"收敛成有依据、有先后、可确认的方向提议，
然后逐条转成 PRD（进 `docs/prd/`）。它把外部 PM 框架（outcome-roadmap / prioritization-frameworks）的方法
提炼到 OperMind 语境，不做对外产品的市场调查仪式。

## 链式流程（用户请求"规划方向 / 下一步"时执行）

### 第 0 步：先对齐意图（必须）
**先**运行 `superpowers:brainstorming` 与用户对齐：目标、约束、取舍、边界。
不先聊透就产出方向 = 重蹈 Codex 跑偏。产出「已对齐意图」一两句话。

### 第 1 步：列候选（只列主脊内）
从 `docs/产品定义.md`、`docs/路线图.md`、既有 PRD、未决需求里列出候选需求。
只列正式产品边界内（会话 / 服务中心 / 多 Agent 内核 / Connector-Tool / 安全治理）的东西；
排除 demo、靶场、演示叙事。

### 第 2 步：用优先级框架排序（提炼，不照搬）
不跑完整 ICE/RICE 打分（缺市场数据）。用「问题驱动」排序，回答四个问题：
- **谁被卡住**：这个需求解决谁的什么问题（用户故事级别）？
- **是否主脊**：是否支撑产品主线（会话主入口 / 服务中心 / 安全闭环）？
- **依赖先后**：是否被更基础的东西挡住（如 P4.2 是 P5 的前提）？
- **最小切口**：能否拆成 1–3 切片的可独立验收包？

输出排序理由（1–3 条/项），不用打分公式。

### 第 3 步：产出一阶段路线提议（结果导向表述）
用 outcome-roadmap 的方法（不整套照搬）把排好的候选写成"结果导向"表述：
```
阶段 <X>：<一句话结果> —— 使用户能 <达成什么>，以便 <带来什么价值>
```
按阶段列出（P4.2 → P5 → P6+），标注依赖与切口。

### 第 4 步：用户确认方向
把提议交用户：只需看 阶段顺序 / 每阶段结果 / 下一步做哪个。
**用户拍板后**才进入单条 PRD 写作（`prd-writing`）。

### 第 5 步：落盘成索引
把确认的方向更新到：
- `docs/prd/README.md`（「当前进展」表，标注阶段顺序与状态）
- 阶段总览段（对齐 `docs/路线图.md`）

## 多维度轨道 + 依赖停车（P4.3 起生效）
PRD 不是"一个域串行"，而是**多维度独立轨道**（会话/内核、服务中心、监控、模型、审批、知识库）。
- **每条轨道只写不被阻塞的 PRD**：依赖未落地（如 P4.3 依赖 P4.2）的 PRD 先"停车"——标记为「已确认 · 待 <依赖> 完成后执行」，不进执行队列。
- **停车原因**：PRD 是执行 AI 的唯一事实来源；被依赖挡住的 PRD，其前提假设可能因依赖方案调整而变，提前写满等于押注返工。
- **空出来的名额**：写另一个不被阻塞的维度（如 P4.2 执行期间写模型设置 PRD）。同阶段不同域可并行。
- **排程检查**：每次规划前先过一遍依赖图（谁被谁挡住），把可执行的和停车中的分开列。

## 产物
- 方向提议（对话内呈现，用户确认）
- `docs/prd/README.md` 的进展表更新（确认后）

## 关键纪律
1. **方向是用户的**：本 skill 只收敛、排序、表述，不替用户拍板"做不做、往哪走"。
2. **先对齐再排序**：意图没聊透不出提议。
3. **主脊内只列**：排除旁路 / 演示 / 旧技术切片升级。
4. **结果导向**：阶段写"使用户能达成什么"，不写"实现 X 功能"。
5. **依赖先行**：有前置的排前面（P4.2 → P5 的天然依赖）。
6. **不照搬外部框架**：只提炼方法（结果表述 / 优先级维度），不做市场调查仪式。

## 常见错误
| 错误 | 修正 |
|---|---|
| 跳过意图对齐直接列清单 | 先 brainstorming，再列候选 |
| 把 demo / 靶场排进方向 | 只列正式产品边界内需求 |
| 用 ICE/RICE 硬打分（无市场数据） | 用"谁被卡住 / 主脊 / 依赖 / 切口"四问 |
| 阶段写功能清单而非结果 | 用"使用户能达成 X"表述 |
| 替用户拍板方向 | 只提议 + 交用户确认 |

## 红灯（STOP）
- 意图未对齐就产出方向
- 候选里出现产品边界外的东西
- 阶段表述是"实现 XX 功能"而非"使用户能达成 XX"
- 没有明确的"下一步做哪个"
- 未列依赖先后

**发现任一红灯 ⇒ 回到第 0 步或第 2 步，不继续。**
