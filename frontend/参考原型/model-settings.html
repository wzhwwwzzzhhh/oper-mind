✓Coordinator 只负责路由，不直接获得任意服务访问权
✓DB / Server / Log Agent 只能调用各自注册的受控 Tool

✓Debate、Reflection 和 Report 只处理结构化诊断结果
✓高风险动作仍需提案、人工审批、白名单执行和验证
